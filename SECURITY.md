# Security policy

## Supported versions

Andarun has no release yet. Security fixes go to the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately on GitHub instead: open the repository's **Security** tab and choose **Report a vulnerability**. Include the steps to reproduce, what an attacker could do, and the commit you tested against.

I aim to acknowledge reports within seven days and will keep you updated until the issue is resolved.

## Scope

In scope: the code in this repository, including authentication, sessions, invitations and access control.

Out of scope: vulnerabilities in Django or other dependencies (please report those upstream), and issues that require physical access to a member's device.
